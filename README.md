# Student and Teacher Class Program

## 📌 Description
This Python program demonstrates the basics of **Object-Oriented Programming (OOP)** using classes and objects.

The program creates two classes:
- `student` class to store student details and perform student activities.
- `teacher` class to store teacher details and perform teaching activities.

It shows how multiple objects can be created from the same class and how object attributes can be modified after creation.

## 🚀 Concepts Covered
- Classes and Objects
- Constructors (`__init__` method)
- Instance Variables
- Instance Methods
- Creating Multiple Objects
- Updating Object Values

## 🛠️ Program Explanation

### Student Class
The `student` class contains:
- `name`
- `age`
- `marks`

It also has a method:
- `study()` → Displays that the student is studying.

### Teacher Class
The `teacher` class contains:
- `name`
- `age`
- `salary`

It also has a method:
- `teach()` → Displays that the teacher is teaching.

## 📂 Objects Created

### Student Objects
- `s1` → Default student details
- `s2` → Student details updated with new values

### Teacher Object
- `t1` → Teacher details updated with name, age, and salary
